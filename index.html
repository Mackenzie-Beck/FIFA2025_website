User Guide

Basic Gameplay Loop

The goal of the player is to use terms from the term set to construct equations in the equation template, which, when rendered on the world grid should form a line connecting the players ship to the goal (a red wormhole). For every correct quesiton the player gets a point which can be used to skip questions.

World Grid

The game space is a cartesian grid represented by a set of axis. THe grid is overlayed over a space background to contribute to the space theme of the game. The player position is marked by a yellow ship sprite, while the goal position is marked by a red wormhole.

A close up of the player and goal sprites at grid locations (-1,0) and (0,1) respectively

Equation Template and Term Set

The player solves problems by using the terms provided by the term set to create equations in the equation template.

An example of a player creating the correct equation to solve a problem. Notice how the line rendered updates based on the equation template.

Points and skips

The player earns a point for every question answered correctly. If they have at least two points then the player can skip a question they find too difficult.

Create and load custom question sets

The user can upload a custom set of questions to the game to tailor the difficulty.
